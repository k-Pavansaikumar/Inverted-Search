# Inverted Search Project

## Project Definition

Inverted Search Project is a C-based application that creates an index database by mapping words to their respective files for efficient and faster searching.

The project uses hashing and linked list data structures to store word information, file details, and word occurrence count. It allows users to create, display, search, update, and save the database.

## Features

- Create an inverted index database from multiple text files
- Search words and display their occurrence details
- Display the complete database
- Save database information into a backup file
- Update database from previously saved data
- Uses hashing for faster word searching

## Technologies Used

- C Programming
- Data Structures
- Hash Table
- Linked List
- File Handling
- Dynamic Memory Allocation

## Learning Outcomes

- Understanding the implementation of an inverted index system
- Working with hash tables for efficient searching
- Implementing single linked lists in C
- Handling multiple files using file operations
- Managing dynamic memory allocation

## How to Run

Compile:
make

Run:
./inverted_search <file1.txt> <file2.txt>

Example:
./inverted_search a.txt b.txt

## Operations

1. Create Database  
2. Display Database  
3. Search Database  
4. Save Database  
5. Update Database  
6. Exit
